# Relational universe research archive (phases 27–154)

This isolated archive complements the existing ABL causal belt and AQD research. It does not modify interpreter, application, or deployment. Run each script from this directory with Python 3.10+ (stdlib): phi_algebra_discovery.py, phi_regime_discovery.py, phi_gluing_experiment.py. Each regenerates its adjacent JSON. Local reruns matched the saved JSON byte-for-byte. Consult raw output for exact metrics.

## Experiments retained
- MetaAlgebra: 4352 distinct candidate maps, 6 deterministic families (369 trials each), 4 stochastic controls (369 each); active vs random provisional probes; validate all 8 inputs before claiming finite-domain equivalence. Fallback table is not a newly invented algebra. Rare behavior detection is not probability estimation.
- Polymath: 369 switching and 369 stable runs; A/B/A/C/unknown/A schedule, 8% measurement corruption; fixed, reactive and adaptive comparisons. Unknown is a category, not a discovered equation. Boundary conjugacy exhaustive over 8! bijections; increment/decrement 8 maps, increment/XOR4 zero.
- Gluing: binary edge constraints on 3x3 and 9x9 grids, cycle syndromes, minimal repair ambiguity, corner blind spots and coupled dynamics. 256 of 4096 edge assignments globally consistent; 144/144 single and 10292/10296 double corruptions detected. Consistency is not historical truth; never silently apply an ambiguous repair.

## Validation gates
1. Identity/inversion/composition, finite domain closure and counterexamples.
2. Boundary reconstruction only for declared structured families, compare bits including metadata and deltas against conventional baselines.
3. Geometry recovered up to declared gauge; arbitrary adjacency does not uniquely determine metric.
4. Causal replay, duplicate/conflict handling, provenance, model drift and unknown domains.
5. Global sections/obstructions, repair candidates with ambiguity and historical anchors.
6. Next: bounded graph rewriting with resource/fuel budgets, adversarial disconnects, no automatic privilege escalation, exact replay and independent oracle.
