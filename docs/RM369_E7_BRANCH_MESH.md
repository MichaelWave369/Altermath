## Growth and topology

One to nine Fibonacci waves: 1,1,2,3,5,8,13,21,34 nodes (88 total at cap).
Each node owns an independent E6 regional field of depth 2..4. Wave
growth is a static deterministic construction, not an autonomous
adaptive growth algorithm. Field IDs are separate from local orientation
IDs. Parent metadata uses round-robin assignment to the previous wave.
The tree connects these parents; the mesh adds undirected same-wave
ring links, deduplicated for groups of two. The chain is an equal-node
control. All edges have unit cost. No golden-ratio physical claim.

At seven waves there are 33 nodes; chain/tree have 32 edges, mesh 62.
The topology comparison is deliberately unequal-edge, so any improvement
cannot be attributed specifically to Fibonacci growth. A matched
edge-count/randomized topology comparison is a future gate.

## Routing and transactions

Breadth-first routing chooses a minimum-hop path among permitted nodes
and enabled links; sorted neighbor IDs break ties deterministically.
Budget is unit edge traversal cost, not measured CPU or network usage.
The standalone route helper expects a graph generated by topology(),
not arbitrary untrusted graph objects.

A request specifies start, target field, local orientation node, gear,
expected state digest and budget. An external fixture grant binds the
same state digest, exact requested edit, allowed nodes, disabled links
and maximum budget. One step is reserved for the local gear; remaining
fuel bounds route length. Denied, stale, malformed or unreachable edits
throw before replacing any field. Successful edits clone the target
field, compose the E2 gear, replace only that field, and produce a
deterministic SHA-256 receipt. Digests bind canonical logical snapshot
bytes and topology, not live hysteresis history. They are not signatures,
replay protection for identical logical states, or authenticated grants.
No live capability invocation or distributed synchronization.

The digest scans all field snapshots and the edit clones the target;
this is not a measured low-latency architecture. Intermediate fields
are not modified. Node grants are fixture authorization only, and the
graph is public within this simulator.

## Controls

Enumerate all 528 unordered pairs at seven waves, mean and maximum hop
distance, number within four hops, and reachable pairs after every single
edge removal. Record the complete per-edge outcomes, mean and worst
case. First root edge remains a bridge even in the mesh; retain that
negative result. Tests independently enumerate reachability after
each link failure. A targeted demonstration disables edge 1:2 and
routes 1->3->2 using two hops plus one gear step, with stale-state,
budget, grant and isolation negatives. E2 inverse gear restores the
canonical logical state, not representation history.

No existing E6, ABL, Codex or NBGPocketMesh code modified. E8 should
compare matched edge budgets and alternative growth laws, introduce
explicit observation/activation contracts, and preserve independent
source receipts. No claim that Fibonacci is optimal.
